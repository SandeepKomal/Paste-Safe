# Security

If the page can be made to leak data (send a request, execute pasted content, get around the CSP), please report it privately via **Security → Report a vulnerability** rather than in a public issue.

For a missed secret format, a normal issue is fine. Include a fake example, never a real one.

Paste-Safe only catches formats it has rules for, plus random-looking strings. It won't catch customer names or other sensitive text that isn't a credential, and it can't protect you from a compromised browser or extension.
