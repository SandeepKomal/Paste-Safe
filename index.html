How it works

      
    
        
  1. 
          
    Find
    
          
    Patterns for well-known formats such as AWS, GitHub, Stripe and JWTs catch keys and tokens. Settings like DB_PASSWORD=, passwords inside URLs, emails, IPs and internal hostnames are caught too. Long random-looking strings are flagged even when no pattern names them.
    
        
    2. 
        
  2. 
          
    Swap
    
          
    Each distinct value gets one label, like [AWS_KEY_1], everywhere it appears. The AI can still tell that two lines mention the same host or key.
    
        
    3. 
        
  3. 
          
    Restore
    
          
    Labels in the AI's reply are swapped back for your real values, so you can run its commands or apply its fix straight away.
    
        
    4. 
      

    


    

      
What to know

      

        
It can miss things.
Detection is pattern-based. Read the safe text before you paste it anywhere.

        
Nothing leaves this tab.
There is no server. The page's security policy blocks it from sending data, and the counter at the top shows requests to other sites.

        
Nothing is saved.
Close or reload the tab and your text and labels are gone.
