How your text stays in this tab

Security

Paste-Safe is built so that your text cannot leave this tab. The browser enforces that, not a promise.

What this page cannot do

Every page carries a Content Security Policy. Your browser reads it before running anything and blocks whatever it does not allow.

connect-src 'none'
No network requests at all. The page cannot send your text anywhere, even if its own code tried.
script-src 'self'
Only this site's own scripts run. Nothing pasted, and nothing from another site, can run as code.
style-src 'self' · font-src 'none'
No third-party styles or fonts, so nothing is fetched that could tell another site you are here.
form-action 'none'
No form can submit your text to another address.
base-uri 'none' · object-src 'none'
Links cannot be redirected and no plugins can load.
referrer: no-referrer
Links you follow from here do not tell the other site where you came from.

Check it yourself

  1. Open your browser's developer tools and go to the Network tab.
  2. Paste a log into the tool, copy the safe text and put an answer back.
  3. Every request in the list is to this site. The counter in the header shows the same thing: 0 requests to other sites.

What it does not protect against

  • Formats it has no rule for. It catches the secret formats it knows plus random-looking strings, not customer names or other sensitive text. Add those to your own word list.
  • A compromised browser or a browser extension that can read every page.
  • What you paste after copying. Always read the safe text before you share it.

Report a problem

If the page can be made to leak data (send a request, run pasted content, get around the policy above), please report it privately so it can be fixed before it is public.

Report a vulnerability Report a missed format

For a missed secret format a public issue is fine. Include a made-up example, never a real one.
