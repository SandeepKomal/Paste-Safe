Source

All of Paste-Safe is open source. There is no build step and no server code: what you read is what runs in your tab.

View on GitHub Download a copy

What is inside

src/core/
The detector: the rules for each secret format, masking and putting the real values back.
src/ui/
The page: highlights, the list of findings, copy, the scroll effects and the film.
css/style.css
Every style on the site, in one file.
sw.js
The service worker that lets the site open offline. It only stores this site's own files.
tests/
Unit tests for every detector, and browser tests in Chromium, Firefox and WebKit on desktop and phone sizes.

Run your own copy

Any static web server works. For example:

git clone https://github.com/SandeepKomal/paste-safe.git
cd paste-safe
python3 -m http.server 8000

Then open http://localhost:8000. To check a change, run npm install, then npm run check and npm run test:e2e.
